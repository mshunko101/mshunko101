**Научно-исследовательский проект: «Каскадная модель развёртки» (2021 - 2026)**

Разработал две связанные системы уравнений — дискретное отображение с показателем $\(2/3\)$ и трёхкомпонентный каскад с фикс-поинтом $\(b^* = 4/9\)$. С помощью инструментов генеративного ИИ проверил интуицию, развил модель и оформил результаты в серию из 8 научных статей на платформе Engee (engee.com). Результаты включают структурное соответствие констант каскада метрике Шварцшильда, интерпретацию замедления времени через ζ-порог и концепт гибридной аналоговой арифметики (ГАРЧАН).

**Технологии:** Python, Julia, Engee, numpy, matplotlib, численное моделирование
